# kachina-wx

Weather data for Cooper Marketing & Media (coopermarketing.org/tahoeweather) and the KSEF Snow Desk.
Built by Kachina on GitHub Actions at 0350, 0950, 1550 and 2150 Pacific from public sources:
Kirkwood stations, Open-Meteo, NWS, UC Berkeley Central Sierra Snow Lab, NOAA CPC.

Files: `cmm_winterdesk_auto.json`, `ksef_snowdesk_auto.json`, `ksef_teamroom_auto.json`, `run_report.json`.
Manual run: Actions tab, kachina-wx, Run workflow.
